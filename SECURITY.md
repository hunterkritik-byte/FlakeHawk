# Security Policy

## Reporting a vulnerability

Please do not open a public issue for a suspected security vulnerability.

Use GitHub's private vulnerability reporting when available, or contact **hunterkritik@gmail.com** with the affected version/commit, reproduction steps, impact, and relevant logs or proof of concept.

Do not include secrets or personal data in reports.

## Scope

FlakeHawk parses CI test-result files and can integrate with GitHub APIs. Security reports involving parser denial-of-service, unsafe file handling, credential exposure, command execution, or GitHub permission misuse are especially relevant.

## Supported versions

Security fixes target the latest release and, when practical, the immediately preceding release.
